# 성공 지표 측정 프로토콜

자동 측정(M3·M4·M6, 실행 시간, 모델 호출 수)은 `node web/scripts/measure.mjs`가 하고 결과를 `docs/measurements/<날짜>.json`에 쓴다. 이 문서는 사람이 재야 하는 M1·M2·M7의 절차다. 측정 전까지 PRD의 모든 지표는 `미측정`이다.

## 준비

- 환경: 배포 URL 또는 로컬(`BANGJI_FAKE_MODEL` 여부를 시트에 기록)
- 참가자: 이 제품을 처음 쓰는 사람 N명(권장 5명 이상). 참가자에게 시나리오 종이(PRD 3.1)와 데모 게시판 URL만 준다.
- 각 참가자는 새 브라우저 프로필(게스트 쿠키 없음)로 시작한다. 진행자는 도와주지 않고 관찰만 한다.
- 시작은 첫 화면 로드, 끝은 각 지표 정의의 완료 조건이다(PRD 성공 지표 표 참고).

## 스톱워치 시트

- 측정일: ____  / 환경: ____ / 모델: 가짜 ☐ 실제 ☐ / 참가자 수 N: ____

| 참가자 | M1 시작→수집 계약 저장(초) | M2 시작→첫 결과 보드(초) | M7 결과 보드→맞춤 이력서 내보내기(초) | 도움 요청 횟수 | 막힌 지점 메모 |

기록 규칙:

1. 중도 포기·실패는 시간을 비우고 메모에 사유를 쓴다. 성공률은 `성공 수 / N`으로 따로 적는다.
2. 대기 시간(모델 응답, 수집)은 포함한다. 진행자 설명 시간은 제외하고 스톱워치를 멈춘다.
3. 목표 달성 여부는 PRD의 각 지표 목표와 비교해 `달성`·`미달`로만 적고, N이 작으면 표본 한계를 함께 적는다.

## 결과 반영

측정이 끝나면 시트와 `docs/measurements/*.json`을 근거로 PRD 성공 지표의 `미측정`을 측정값과 측정일로 바꾼다. 측정하지 않은 값은 채우지 않는다.
